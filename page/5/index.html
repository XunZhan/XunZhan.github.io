42. Trapping Rain Water

Posted on 2022-04-20 Edited on 2023-07-06 In Leetcode

Problems

Given n non-anegative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

Leetcode

Examples

Constraints

Solutions

Brute Force

Do as directed in question. For each element in the array, we find the maximum level of water it can trap after the rain, which is equal to the minimum of maximum height of bars on both the sides minus its own height.

Algorithm
  • init ans = 0
  • iterate height from left to right:
    • init left_max = 0, right_max = 0
    • iterate from current element to the beginning: left_max = max(left_max, height[j])
    • iterate from current element to the end: right_max = max(right_max, height[j])
    • Update ans += min(left_max, right_max) - height[i]
Complexity

Time: O(n^2)
Space: O(1)

Dynamic Programming

In brute force, we iterate over the left and right parts again and again just to find the highest bar size up to that index. But, this could be stored. Voila, dynamic programming.

Algorithm
  • Find maximum height of bar from the left end upto an index i in the array left_max
  • Find maximum height of bar from the right end upto an index i in the array right_max
  • Iterate over the height array and update ans
Complexity

Time: O(N)O(N)O(N)
Space: O(N)O(N)O(N)

Monotonic Stack

Instead of storing the largest bar upto an index as in approach 2, we can use stack to keep track of the bars that are bounded by longer bars and hence, may store water. Using the stack, we can do the calculations in only one iteration.

We keep a stack and iterate over the array. We add the index of the bar to the stack if bar is smaller than or equal to the bar at top of stack, which means that the current bar is bounded by the previous bar in the stack. If we found a bar longer than that at the top, we are sure that the bar at the top of the stack is bounded by the current bar and a previous bar in the stack, hence, we can pop it and add resulting trapped water to ans.

Algorithm
  • Use stack to store the indices of the bars
  • Iterate the array:
    • While stack is not empty and height[current] > height[st.top()]
      • It means that the stack element can be popped. Pop the top element as top
      • Find distance between the current element and the element at top of stack, which is to be filled: distance = current - st.top() - 1
      • Find bounded_height: bounded_height = min(height[current], height[st.top()]) - height[top]
      • Add the trapped water to answer: ans += distance * bounded_height
    • Push current index to stack
    • Move current to next position
Complexity

Time: O(N)O(N)O(N)
Space: O(N)O(N)O(N)

Two Pointers

As in approach 2, instead of computing the left and right parts separately, we may think of some way to do it in one iteration.

From the figure in dynamic programming approach, notice that as long as right_max[i]>left_max[i] (from element 0 to 6), the water trapped depends upon the left_max, and similar is the case when left_max[i]>right_max[i] (from element 8 to 11).

So, we can say that if there is a larger bar at one end (say right), we are assured that the water trapped would be dependant on height of bar in current direction (from left to right). As soon as we find the bar at other end (right) is smaller, we start iterating in opposite direction (from right to left).

We must maintain left_max and right_max during the iteration, but now we can do it in one iteration using 2 pointers, switching between the two.

Algorithm
Complexity

Time: O(N)O(N)O(N)
Space: O(1)O(1)O(1)

也许是投其所好，每每时至黄昏，就能听见从远处传来的歌舞声，只是在乐师看来，穿过层叠暮霭与重仞宫墙的，倒像一曲悠长的挽歌。寻回身份本该尽兴而奏，乐师反倒被什么心事烦扰，在寥寥几拍后便停了手，坐在筑旁出神。临近飧时，将领带着侍从前来掌灯，而后献上君王的邀请。

乐师被人领着穿过蜿蜒的幽径，抵达一处偏院，内室隐于栉比鳞次的翠竹里，竹叶中透出柔和的烛光，这是一个被星火点缀的冬夜。
君王负手而立，在窗前缓缓转过身。他只着玄端，褪去一身冕服时的凛然，问道：“夜半相邀，没有打搅先生吧？”
“得陛下赏识，幸莫甚焉。”乐师在席前放下琴匣，执尺抚弦。
落座的君王递上茶盏，示意并不着急演奏的开场：“先生做酒保多久了？”
“十年有余。”
“习筑可曾师从名家？”
“未曾。不过是闲来无事，酒后怡情。”
“只为怡情？”
“若能达至臻之境，自然也能以筑为笔绘山河，以曲为楫溯旧景。”
君王挑眉，仿佛听到什么趣事：“先生想看何种山河，又想回何日旧景？”
并非只有刀光剑影才算兵戎相见，这问题来得轻巧，却像把淬毒的刃，顺着经脉挑开肌肤，然后静待毒液流入四肢百骸。被划伤的乐师僵在原处，蜷在掌心的衣角溢出几条慌乱的皱褶。
嬴政觉察到他的回避，便由着乐师缄默良久。末了，大抵是想要调整姿势，乐师的袖子扫过茶盏，将其掀翻在地。他自觉失态，匆忙去捡，却被嬴政握住手腕：
“陈舟既已作沉舟，不如提笔扬楫做回自己，高先生……以为如何？”
预料之内的局面，君王已经给足了时间容他做出反应，高渐离此刻竟觉得安心。他抽回手摆好茶具，顺水推舟：“听凭陛下差遣。”

【3】
嬴政并不打算公开高渐离的情报，然而成为陛下的新宠注定难逃觊觎，被圈禁的御用乐师是荆轲挚友的消息一天之内就已经传得沸沸扬扬。

翌日，左右相国一改剑拔弩张的对峙，联合群臣上书对高渐离的惩治。嬴政看着长篇累牍的谏言觉得好笑，什么误国，什么宿仇，区区一个乐师竟让满朝文武避之不及。但两手一摊显然不是上策，他从中斡旋，撤除那些无中生有的罪名，妄图让乐师不至于方才解脱便又身陷囹圄。

到底是权钧力齐，两位相国做了充分的准备，早朝过半仍旧在为乐师的处罚拉扯。嬴政俯视喋喋不休的大臣，将竹简捏得直响。他讨厌无法掌控的棋局。

退朝的时候行刑刚刚结束。
还未踏入宫门便有刺鼻的气味扑面而来，呛得嬴政一阵干咳。忽略侍从先清理院内的请示，他快步跨过门槛，只见高渐离被反剪着双手押跪在庭院，他的脖颈被大力地按向地面，直逼燃烧着木柴和浆泥的铜盆。没有一丝挣扎，他用仅剩的力气维持身形，笔直的背脊撑起白衣扎进浓黑的烟火里，嬴政觉得心惊，飞蛾赴火也不过如此场景。

“高先生……” 嬴政蹲下来扶起高渐离，本想说些什么，看见乐师铺满烟灰的脸上被烤干的泪痕划出细碎的裂纹，几欲昏厥仍推开他的手臂哑声拒绝，他竟一时失语。

高渐离不知道自己是怎么回到枕衾间的，周围不见五指，但温暖而柔软的触感给了他很大的慰藉，便也不去纠结自己是梦是醒。身上的被褥逐渐变重，他想起这是与某人同寝时才有的待遇。
“大哥？” 他的声音经过炙烤后已经成了一块撕裂的腐木。
“嗯？还冷么？” 荆轲确认似的又将被角压紧。
“大哥……” 他的四肢疼痛僵硬，不得不维持着原先的姿势。
“我去烧水，别乱动了。” 荆轲边走边说：“叫你多穿点，真是一点话都不听，这下病了……你看看，我现在哪有大哥的样子……唉。”
他失笑，都这样了还要争个高低。
意识逐渐混沌，他向荆轲离开的门口张望。
那里空无一人，黑洞吞噬着周围并不断放大，最终扩张到他的全部视线。

晌午之后，高渐离终于转醒，虽然对他而言从此昼夜无别，他仍试图以其他方式感受光明。眼眶时而刺痛时而酸胀，他花费不少功夫摸索到窗边的矮凳，又唤宫女取出筑。

一切都要重新开始，自然也包括击筑。于是他披着暖阳，从最基础的指法尝试。他在简短的音律里走走停停，不知不觉被牵着回到师门的光景。

他的师傅虽在蓟城有些名气，却并不属于当时显赫的任何一个流派。这位年过花甲的老师既不教他韶派的雄浑中正，也不授他羽派的旖丽灵动，十二年的玉汝于成，督促他练的只一个“真”字，弦从心动，境携曲行。也是相似的窗边，老人提着他的腕带他感受轻重缓急，有流传的调，有现编的曲，都好听。

偶尔也有耐不住性子的时候，基本功的练习枯燥繁杂，远没有燕市的酒有吸引力。他在燕市还有朋友，肉铺的老板喜欢他的曲，经常叫上另一位听众约他小聚。陈年的烈云烧配上刚出炉的烤肉，作为回馈，他搬出新作。听众既没有食物招待，也不会乐器，但他不止是听。
不同于定居在蓟城的两位，听众走过很多地方。
“阿离，邯郸和朝歌有很多好玩的，等有机会了我一定带你去！”
“谢谢荆先生。”
“榆次也不错，” 荆轲挠挠头：“只是我在那里遇到很多高手还技不如人……也就不是很想回去。”
“天外有天，荆先生的剑术也绝非平庸之辈。” 荆轲的剑舞的确好看。
荆轲抚掌而笑：“改日阿离想学，我定倾囊相授。”
“那就先谢过荆先生了。”
往往这时，高渐离才像是真正的听众，听行侠仗义的故事，也听失意落魄的叹息。

当荆轲意识到自己说得太多时，通常酒已经喝完了。高渐离的曲还没弹，但是他的嘴闲不下来。他就品高渐离的曲，竟也言必有中。高渐离惊喜而欣慰，便又捻来些小调，间奏时荆轲不禁高歌几句，从《鹿鸣》唱到《桑扈》，最后竟与他唱起《黍离》。

高渐离自歌声里醒来，意识到声音的源头仍旧是远方，他皱着眉头把那些画面丢进风里。竹尺快凉透了，他渡过去些手心的温度，然后补上未完的练习。
荆轲话多，好在他全都愿意听。

【4】
待到太医允许他出门走动，高渐离已经习惯了昼夜无别。眼前的疼痛也为他带来几抹色彩，他边走边回忆，旧时的画面模模糊糊印在那片黑暗里，让他一时间分不清今夕何夕。宫女领他至中庭，不过几步后手臂就被骨节分明的手掌接管，他犹豫片刻，然后稳当当跪下去：“陛下。”
嬴政为他披上大氅，又将人托起：“高先生好些了吗？”
“陛下体恤，目盲而已，在下四感俱在，自当承蒙惠允。”
“气话，” 嬴政不在意他的僭越，扶他到庭中的鱼池边落座，鱼儿逃似的远离倒影，“高先生不见朝中的明争暗斗，自然不解朕的决定。只是这绕梁余音，朕不愿它囿于一隅之地。”
一隅之地？高渐离在心里冷笑，如今所处相比燕国，才更像一隅之地。
他忆起学成后的游历，素日古板的师傅想也没想地同意，他便去赴荆轲的约。二人同游邯郸朝歌，他在各处演奏，荆轲总是倚在不远处直至曲终。一路相伴，从籍籍无名到座无虚席，荆轲做他的挚友，走进他谱的每一首曲。
“渐离，有一个好消息，我要留在蓟城了。”
“很久吗？”
“也许是很久，”荆轲神神秘秘的凑近他耳边：“毕竟我马上就是太子府上卿嘛。”
“真的？” 他喜出望外：“那我先恭喜大哥！”
荆轲搂过他的肩，笑得愈加爽朗：“走，大哥带你去尝尝新酿的酒！”
那时的他以为是命运献上佳酿，敬一段历久弥坚的情谊，却未曾想到这不过是诀别前的一场饯行。

“高先生？” 嬴政料他出神，不难为他作出回应，识趣地起身：“风寒露重，早些休息。”
君王习惯于极目远眺，高台之上，江山为棋。然而乐师的心思敏感到足以捕捉常人无法察觉的情愫，析毫剖厘，再细心整理。他拾起君王看不见的落叶，也收藏的君王听不见的思念。他并不经常能听清君王的关心，数月里天翻地覆的变化已然来不及消化，旧日的场景又蜂拥而至，将思绪搅得混乱，他只能用长久的沉默平息。

【5】
宫里的时间过得飞快，高渐离在一声声祭乐里辨出元日的到来。
咸阳的冬天常是雨雪交加，不过走几步衣服便已浸湿大片。他不喜欢黏腻的触感，于是躲进屋里听雪。燕国的雪飒沓又泠冽，不似这般缠绵，刮过肌肤留一条直挺挺的伤口，总好过寒气慢条斯理的侵入。他刚想猫回被窝里，就听见宫女在屋外请安。
嬴政带着侍从进来，打断高渐离的行礼，他向乐师的手中递上温酒。
君王本不该至此。再自命清高也该懂得适可而止，他与对方寒暄然后被问及心愿。

半晌无言。
“大哥没有愿望吗？” 高渐离知道荆轲有事瞒着他，可荆轲不说他也不想开口烦扰。他只得换个话题等荆轲露馅。
“有啊，我想下个元日还和渐离一起过。”
“那，一言为定！”，这四个字他说的极响，就要赶上他高歌的音调。
“一言为定。”
他确信当时郑重地接过这份承诺，他也确信荆轲将这份承诺记在心里。只是这样的愿望对一个国家来说终究太过微不足道，山河破碎时没有任何东西能幸免于难。
他让君王在静默中等了许久，像是害怕降罪于自己的不识礼数，他从回忆里抽身，恭敬地递上心愿：
“在下愿千乘之国，海晏河清。”
不必纠结是否肺腑之言，高渐离明白，就算弹到十指皲裂，在君王的眼里不过是燕雀啼血。

正文

高渐离初来忘川的前几天，使君发现他身上的伤痕可以说是与日俱增。
虽然有大小事务缠身，使君还是抽出了整整三日陪着这位目盲的乐师。从三世楼到金戈馆，从棠梨坊到逸趣阁，甚至连住所的每个角落使君都耐心领着他走过几遍。
也许是前世已经习惯用其他感官代替眼睛，即使身处完全陌生的环境，高渐离也未有丝毫慌乱。他安静的听着使君介绍各处，其他名士上前问候也含笑回礼。倒是使君自己，总在高渐离靠得过近时乱了气息。

眼见那些淤青从他的五指蔓延至脚踝，使君便又告假半日去了趟高渐离的住所。木门轻叩不过两声，便听见内里传来句沉稳的“稍等”。使君却候了不知道多少个稍等后，才见门扉缓缓打开。
“高先生，您没事吧？”，他的脚尖似又添了道新鲜血痕。
“说来在下正准备与使君商量这事”，明明自己受了伤，高渐离的笑里却带着歉意，“但前几日已经耽误使君太久，在下想等使君有空时再登门。”
“不不不……”，使君实在受宠若惊，在他之前入住的几位皆为王侯将相，阎君拨的人手不够时，她还要亲自伺候起居。犹记系某人的佩绶时仅差半寸没有对称，便被一顿数落。此时使君竟也顾不上对方看不见，兀自摇着手道：“只要先生有求，我再忙也是要接待的。”
“使君辛苦。”高渐离作揖，“不妨先进来坐。只是屋内还有些凌乱，让使君见笑了。”
“凌乱？”使君不解道。
待到进屋后，只见桌案与地面都堆了小山似的几箱礼物，又见柜子上新添了几只花瓶，也不知谁还送来了雕花的贵妃榻，一改从前的冷清，颇有些贝阙珠宫的味道。
“使君小心，”高渐离先跨过门榄，拦在散落的碎瓷前，“在下方才不小心打碎了太宗陛下送来的一只瓷瓶，尚未清理干净，注意脚下。”
使君向前望去，角落里果然堆着大块瓷片，有几块上沾着斑驳的绯色。
凶手一目了然。
“忘川名士好客，”高渐离走到桌边，边说边摸索着替使君搬出凳子，“在下初到未及半月，几乎是人人都来过了。”
“高、高先生也请坐。”，若不是那几处伤痕，恐怕她真以为高渐离失明不过谣传。
那人慢悠悠落了座，又要斟茶，使君只得眼疾手快夺过茶壶，替他先倒了满杯。
高渐离不禁失笑，“想来使君整日在忘川都是担惊受怕的。”
“还好，还好”，拿多少酬劳做多少活嘛。
“在下一介布衣，使君以后对我不必拘礼。”，高渐离抿了口茶说，“若不嫌弃，力所能及之事也我愿为使君分忧。“
“先生刚来忘川，先休息一段时间罢”，她并没有拒绝，“日后确实有不少活动等您参与。”
“好。“ 薄纱下的眼角又流淌出几分笑意，融进了茶里，阵阵回甘。
二人寒暄时，那双眼睛蛊惑着使君看了又看。若是高渐离选择入宫前的身体，是不是今日就能看见那眸里盛着的灿烂星汉，又或是清溪映月？不等她细想，微风卷起薄纱，像是道封印，颤抖着将那双眼睛连同他的故事尽数锁入岁月。
“……使君？”
“啊……我失礼了”，使君急忙收回目光，“不如说说高先生的事？”
高渐离轻哂，“使君想多看几眼也是可以的。”
真是奇了怪了，使君扶额，那我到底要不要继续看呢。

使君替高渐离整理好房间时，已至深夜。易碎物品被束之高阁，棱角尖锐的家具也被挪至鲜少踏入的区域。唯独那贵妃榻，由于体积过大只得留在原处，不过已铺上厚软的狐裘，再不能伤人了。
高渐离本要将使君送至桃源居，她只得谎称自己可以用三世镜穿梭。阎君早已下旨三世镜不到万不得已或执行任务，绝不可用。但若让目不能视的名士在黑夜独自行走于偌大的忘川，传到阎君处，这个月的月钱怕是又要少掉大半。
她由着高渐离送到门口，却在转身时听见他欲言又止，“使君，我其实还有一事相求。”
“高先生对我也不必拘礼。”
“荆卿”， 月色洒上他覆眼的薄纱，化作眸中的光，“荆卿会来忘川吗？”
“这得看我的运气如何了”，使君如实作答，“寻英池中需以灵偶召唤名士的星灵之力。只是我仅余七只灵偶，也不知道有没有机会。”
“灵偶可有获取的途径？”
“商铺里能买到，有些贵，不过先生放心，我在努力攒钱了。”
“使君量力而行即可”，高渐离偏过头望向远处的寻英池，叹了口气，“荆卿是否愿意来，还未可知。”
他又朝使君深深鞠一躬，“辛苦了。”
使君将人扶起，又叮嘱他早些休息，这才离开他的住所。
而那一袭蓝衣在原地驻足许久后，终于捱不住清冽的月光，静悄悄地消失在门后。

荆轲是被第二十只灵偶带回来的。
使君攒了一月的钱，却也只够再买十三只。不过好在还是来了，她转头去看新来的名士。
黑袍白发的刺客此刻正坐在她身侧颔首敛眸，盯着手上的护甲出神。
当真是……值了值了，值了值了。
“荆先生对住所有什么要求吗？”
“安静一点。”
“好说”，使君眯起眼睛，存心逗他，“那会离高先生住的地方远一些哦。”
“渐离也在这里？”
“在的哦”，她的嘴角快要翘上天边，“怎么样，要不要考虑重新说一下要求？”
“我想住渐离隔壁。”
“那荆先生请随我来。”
使君领着他穿过蜿蜒的街道，说来也巧，荆轲来时正逢梨花盛开，一路上疏疏密密的树枝从名士们的院子里探出来，争先恐后妆点晚春里的忘川。
“渐离在我走后还好吗？”
“不太好，” 话音未落就见不苟言笑的人皱起眉头，她急忙补充，“但是来了忘川之后，高先生常常去棠梨坊与各位名士奏乐，闲暇时还与人相约品茶，生活得倒也算滋润。”
“嗯。” 他不依不饶，“我走后发生了什么？”
使君便将高渐离前世一一道来，本以为说至“乃矐其目”或是“举筑不中”处，荆轲会很是动容，却不曾想除了刚才只一瞬的皱眉，他竟再没有什么反应。
“高先生就住这里，我这就回去了，荆先生。”
“有劳。”

荆轲望着使君远去的背影，也不着急进门。他犹豫过是否要来忘川，他太想放下前世的种种无奈重新开始，却又贪心地想要再见某些人一面。
等到忘川重逢，得知对方竟步了自己的后尘，他又犹豫该以何种心境相见。
他站得太久，久到风吹落大片的花瓣，又替他推开那扇木门。纷繁里有人抱琴倚树，呼吸浅浅，像是怕惊扰薄暮里这一场香雪。
荆轲的靴子在泥土上踩出簌簌的声响，却发现高渐离毫无察觉，不由想起从前高渐离苦于太过敏感的听觉难以入睡。
他想，也许忘川真能许他一夜好眠。
他褪去护甲，指尖却停在了温软的脸颊前。像是有所感应，高渐离歪了歪头。
“醒了？”
“荆卿！” 刻入灵魂的声音自半梦半醒间传来，高渐离几乎是挣扎着起身，“荆卿，是你吗？”
“嗯，是我。” 荆轲一边扶住他的手臂一边握住他的手，重复道，“是我。”
掌心的手颤得厉害，于是荆轲将它攥得更紧。
“我以为……你不会来。”
回答高渐离的是一个沉默而坚实的胸膛。他们之间有太多的话要说，以至于用肢体的接触暂代后，那仍是一个绵长的拥抱，从夕阳西下直到夜幕低垂。

待到漏尽更阑，庭院里架起了小炉，万物沉寂里，唯有木枝在猩红里吱呀的唱。
高渐离忽然伸出手贴近有些不安的火焰。
“冷？”
“许久没有这样亲近万物，” 乐师笑道，“都有些忘了它们的样子。”
“所以渐离如今也更喜欢席地而坐。”
“正是。忘川世外桃源，我自然不愿辜负这一片莺飞草长。”
说完便觉掌心骤暖，有人递上了刚温好的酒。
他用拇指摩梭着，酒盏周身光滑，边角圆润，中间刻着细密的纹路，样式应是条永不停歇的溪流。
“这酒盏别致，不似我们那时的器皿。”
“嗯。” 荆轲同样不曾见过那盏，只道，“是使君送的，她还说这对酒盏声音也好听。”
“声音？”
“也许是这个意思。” 说罢荆轲将手中酒盏小心点在对方的杯沿。
琴师耳边响起一串清脆的音符。
他会意地点头，说道：“确实悦耳。” 骨节分明的手护着酒盏贴近唇边，高渐离轻啜一口，便察觉到荆轲不同以往的迟疑，问：“荆卿不喜欢吗？”
“这酒闻起来……” 荆轲顿了顿说，“很甜。”
高渐离失笑，又像是想起什么，随手往炉火里添了些柴，火光跳着点亮他的小半张脸，他说：“荆卿是习惯了从前的那份浓烈。”
荆轲闻言便将酒饮尽，又透过浅蓝的琉璃去看对面，那人在涟漪里的身影便化作镜花水月，在酒盏里离合流转。他自顾自点点头，权当默认。
“荆卿既来了忘川，也试试其他味道，兴许会有新的发现。” 高渐离说，“日后饕餮居若有酒会，不妨与我同去。”
“自然。”
荆轲虽并不中意使君送来的酒，却还是斟了几杯。
忽有凉风袭来，拂落几朵梨花，掉在他脚边。鬼使神差的，他挪到高渐离身旁。
“荆卿？” 有素白的梨花钻进他的发间。
“我在。” 荆轲被醉意笼着，眉眼也柔和起来，担心高渐离没听见，又像是重新整理了思绪，他说：“渐离，我在。”
高渐离抚上那滴瀛洲玉雨，纤细的指尖轻轻描摹过花瓣的轮廓，他微哂：“荆卿还是像以前一样喜欢看我的笑话。”
荆轲不动声色的脸上终于再难遮掩笑意，“没有，渐离这样很好看。”
“当真？”
“当真。”
他不问他图穷匕见，他也不问他何不复明。全因今夜已是忘川的春夜，那些所有的心照不宣，很快就会融进一杯杯琼浆里，或是加一分甜，或是添一道烈。

后记

其实我想写的画堂春有两层意思，一是高渐离居住的地方被重新布置得宛如画堂，又恰逢晚春；二是当荆轲来到忘川之后，高渐离终于真正意义上等到了友人，他们朝夕相处的种种又是满园春色的光景了：）感觉应该不难看出来……的吧！

我是写了刀的，但写的时候没有意识到。高渐离说自己许久没有亲近自然，其实更是许久没有以这样放松的心态生活。前世在宫中的时候，孤身一人面对陌生世界，又怎么会再感受到“饮于燕市”的那份自在。然后我竟然写酒盏上的刻纹是溪水我真的呜呜，我怎么会这么刀TAT自己重读的时候真的惊呆。

以及荆轲透过酒杯去看高渐离，我本想写他像看水中洛神，但又想到很多不妥的地方，就删了，但又不甘心，就在这里记一笔。虽然我想表达荆轲对高渐离的心意可比曹植对洛神，但一来洛神是女子本就不妥；二是洛神对于曹植来说不过幻念，高渐离却是实实在在的挚友；三是《洛神赋》中人神永隔，但荆高可是在史记里贴贴的人们呀，嘿嘿。

最后想说，很多词语我找了很久，本来以为自己兴致来了一个晚上就能写完。动手之后竟然写了三个晚上，书读的太少了。比如荆轲与高渐离碰杯这段，我才查到先秦是没有碰杯一说的，一般都要遵循礼节互相敬酒，所以高渐离在听到荆轲说酒盏声音好听时会疑惑。不说了，菜就多练，希望下次能写出更好的荆高。

如梦令

正文

“呃……打扰……”, 高渐离的屋门半掩，使君担心他是否又遇到什么危险便进来一探究竟，却不巧撞破满园春色。
“唔——” 高渐离还未反应过来，连人带乐谱就尽数被厚实的被子捂住。
“使君？” 刺客的眼里泛着利刃的光。
“我我我……” 她迅速地转过身，解释道：“我瞧见这么晚高先生的门没锁，有些担心就过来看看。”
“那看完了？”
“是、是……” 她说：“我还有一件重要的事情，想和二位说。”
被窝里探出半个脑袋，笑意盈盈：“使君稍等，是荆卿冒昧了。不如使君在院中静候片刻，待我们收拾一下。”
使君背着身点点头，出了门。

盛夏几乎是片刻而至，使君甚至觉得那场梨花雨就在昨日。也不知怎么，一夜的功夫，蝉声伴着蛙声就喧闹了起来。她又看见脚边的蟋蟀蹦得老高，吓得在那片草地里乱窜。
正当使君觉得可以改日再来的时候，两人的脚步一唱一和由远及近，将她的惊慌尽收眼底。
两人不约而同笑起来，高渐离弯下腰，替她掸去脚后的一只小虫，说：“使君不怕恶灵不怕怨鬼，倒是怕这些小虫。”
“太小了，总害怕它们蹦到我身上。”
荆轲放下背着的手，递到使君面前，掌心躺着一只玉莲花纹香囊[1]。“夏天蚊虫多，使君可以带上这个。” 素白的荷花在风里散着幽香，沁人心脾。
“那我不客气啦，” 小巧的香囊转眼就垂在了她腰间，与环佩轻轻碰撞，犹如弦音。她露出好看的酒窝：“谢谢荆先生！”
“嗯……说来，使君找我们有什么事情？”
话落便见那对酒窝消失在她脸上，使君抬起头，眼中竟也不再盛着光：“我……我要走了。”
“走了？” 高渐离不解道：“使君要离开忘川吗？”
她不回答，只是将三世镜从怀中取出扔在地上，她的身体也随之变得透明起来。
“怎么会这样？” 即使带了半张面具，她还是看出荆轲皱起了眉。
“我不知道，” 她不舍地盯着一同透明的香囊：“明明你们才刚来我的桃源居不久……”
“使君怎么了，荆卿？“
“使君的身体离开三世镜就不能拥有实体。“
“是否有怨灵对你施了法术？”
“最近都没有怨灵。”
“那请阎君大人检查过吗？”
“就是阎君大人说我得走……”
两人对望一眼，不做声了。
“这就是我要说的事情。” 她伸手去攥裙角，却也只能眼睁睁看着手指穿透裙子，慢慢握成了拳。
高渐离捡起三世镜靠近使君，待到透明的身体恢复原样，又握着她的腕，将它塞回她的手里。她听到耳边一声轻叹。
“使君以后要去哪里？” 高渐离问：“在下与荆卿是否有幸同行？”
“不……” 她的鼻尖红了起来，然后蔓延到双颊和眼角：“你们……你们去不到现世……“
“无论如何都不行吗？“ 荆轲似乎还是一如既往的固执。但此刻，她简直太喜欢这种固执了。
她往自己脸上抹了一把：“无论如何，都不可能。“
“那使君今晚就要走？“ 荆轲问道。
“我不知道……“ 她怔怔地坐到草地上，全然忘了那些小虫：”等到三世镜也不能维持我的身形时，我就要走了。“
有什么顺着脸颊不受控制地滑下，在眼前的世界蒙上雾，她说：“我似乎才刚刚上任，才刚刚熟悉你们的喜好……“
高渐离蹲下来，又拉了拉荆轲的袖口示意他坐下。他问：“使君若觉得惋惜，不如趁着今夜再与我们对饮几杯？饕餮居新酿的青梅露已经到了，使君喜欢浅酌，要不要一同尝尝。“
“饕餮居那个要排很久的队才能买到的酒，“ 她吸了吸鼻子，小声说：”要的要的。“

是夜，从前的小火炉变成了冰鉴。
荆轲从屋内搬出了矮桌，又取了三只酒盏。高渐离的筑也被抱出了屋子，像是要加入这场宴饮。荆轲正欲斟酒，便听高渐离说：“荆卿，让使君来吧。“
荆轲并不明白，却也还是将酒壶推至使君身前。
使君将酒盏盛满碧波，她又从冰鉴里舀出几块冰，叮叮当当落进去，再叮叮当当浮起来。
“高先生不喜欢冰饮，“ 她将没加冰的青梅露递给高渐离，”这杯给你。“
“谢过使君。“ 这次的酒盏小而浅，他一饮而尽，察觉身边的人没有动静便问：”使君不喜欢吗？“
“不是……” 她犹豫了一会儿，问：“你们是特意……哄我吗？”
刚说完就看见对面落座的刺客被呛了一口。
“哈，使君原是担心这个。”笑意透过眼前的白纱，几乎快要漫出来：“是特意请使君一起尝当季的佳酿。”
“嗯。” 她也不知道这是不是想要听的答案，抿了一口青梅露，酸酸甜甜的味道带着后劲一股脑冲进胃里，在那处三下两下地轻抚，好不舒服。她不由赞叹：“好喝。不愧是饕餮居。”
“使君若是喜欢，多喝几杯。” 荆轲举起酒盏，他分明也带着笑意。
她看见刺客勾起的唇角，又听耳边响起碧涧流泉[2]，竟真的一盏接着一盏。

酒过三巡，三人中只有她失态得趴在桌上。她又不知道从哪里来了勇气，撑起头来，在座位上张牙舞爪：“我还、还能喝。今晚、要与二位、不、不醉不归！”
荆轲飞快地从后面托住使君，只差一点她就要一头栽进草丛里。“使君已经醉了，我送你回去吧。”
“不、不、我、还没……”
“要不要送她回去？” 他向尚未说话的挚友求助。
高渐离笑着摇了摇头，又走上前去，拍了拍使君道：“使君，你看那边。”
她已经在一片混沌里迷失了方向，却被这声音指引得清明起来。她顺着他修长的指尖看去，不远处隐约有什么乎暗乎明。
“我要被带回去了吗……” 她用手臂挡在眼前似是要做最后的抵抗：“我不想走……”
“使君，若我感知无误，远处应有一片流萤。” 他示意荆轲将人再抱起来一点，又揉了揉她的太阳穴，打趣道：“萤虫翅振细小密集，绝不会是阎君的声息，使君这是真的醉了。”
“你胡说，我没——” 那些萤火虫像是并不怯生，越飞越近，有的甚至擦着她的眼睛过去。“好美，这个。”
“前些日子，荆卿还问为何忘川不见流萤，原来它们是要等到使君光临。”
她感觉自己正小心地被人放平到草地上，天空像轴刚被打开的画卷，缓缓将夜色展示在她面前。那些流萤聚散徘徊，绕得她眼花缭乱，就要看不清荆轲与高渐离。
“我、好像是有点、有点醉。”
“使君，在你睡着之前，可否再听在下与荆卿几句？”
“你、你说……”
“在下来到使君的桃源居，便觉春和景明。不仅仅是因为那时正值晚春，使君的照顾与帮助，比所有的事情都更能温暖人心。”
不等使君回答什么，荆轲便接着他的话：“使君，能与渐离重聚忘川，轲感激不尽。”
她张口想说不必言谢，却没能听到自己的声音，那些萤火逐渐暗了下去，连同这个夜晚，将她裹挟着带入一片黑暗。她只好作罢，想着，明早再收拾这一片杯盘狼藉吧。

手中的身体渐渐消失在萤火中，荆轲抬起头问道：“你知道那是阎君的东西？”
高渐离回答：“我不知道。“
“那怎么不让我送她回去？“
“只是感觉。“ 高渐离伸手去摸她坐过的那片草地，指尖只留下草尖酥痒的触感。“希望她听见我们最后说的那些。”
“会的。” 荆轲望向她还未饮尽的半盏酒，那里还浮着一小块冰。
“走吧，” 高渐离起身，“这些……先别收起来。”
“嗯。”

使君在翌日清晨醒来。她的枕边堆着也不知谁给买的毛绒小兔，窗边的茉莉开得正盛。
她睡眼惺忪地打开音乐软件的每日推荐，第一首的前奏清冽而悠扬，它唱：
“情不敢至深,恐大梦一场,卦不敢算尽,畏天道无常。”[3]
