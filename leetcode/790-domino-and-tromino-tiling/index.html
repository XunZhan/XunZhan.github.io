790. Domino and Tromino Tiling

Posted on 2023-01-06 Edited on 2023-01-11 In Leetcode

Problems

You have two types of tiles: a 2 x 1 domino shape and a tromino shape. You may rotate these shapes.

Given an integer n, return the number of ways to tile an 2 x n board. Since the answer may be very large, return it modulo 10^9 + 7.

In a tiling, every square must be covered by a tile. Two tilings are different if and only if there are two 4-directionally adjacent cells on the board such that exactly one of the tilings has both squares occupied by a tile.

Overview

Here we define the sub problems for our DP:

  1. Fully covered board: All tiles on board are covered by a domino or a tromino.
  2. Partially covered board: Same as a fully covered board, except leave the tile in the upper-right corner (the top row of the rightmost column) uncovered. Note, a board with only the lower-right corner uncovered is also considered “partially covered.” However, as we will discover soon, we do not need to keep track of which corner is uncovered because of symmetry.
  3. f(k)\boldsymbol{f(k)}f(k): The number of ways to fully cover a board of width kkk.
  4. p(k)\boldsymbol{p(k)}p(k): The number of ways to partially cover a board of width kkk.

We can determine the number of ways to fully or partially tile a board of width kkk by considering every possible way to arrive at f(k)f(k)f(k) or p(k)p(k)p(k) by placing a domino or a tromino.

All of the ways to arrive at a fully tiled board of width kkk are as follows:

  1. From f(k−1)f(k−1)f(k−1) we can add 1 vertical domino for each tiling in a fully covered board with a width of k−1k−1k−1. Case 1
  2. From f(k−2)f(k−2)f(k−2) we can add 2 horizontal dominos for each tiling in a fully covered board with a width of k−2k−2k−2. Case 2
  3. From p(k−1)p(k−1)p(k−1) we can add an L-shaped tromino for each tiling in a partially covered board with a width of k−1k−1k−1. We will multiply by p(k−1)p(k−1)p(k−1) by 2 because for any partially covered tiling, there will be a horizontally symmetrical tiling of it. Case 3



Summing the ways to reach f(k)f(k)f(k) gives us the following equation:
f(k)=f(k−1)+f(k−2)+2∗p(k−1)f(k)=f(k−1)+f(k−2)+2∗p(k−1)f(k)=f(k−1)+f(k−2)+2∗p(k−1)

All of the ways to arrive at a partially tiled board of width kkk are as follows:

  1. Adding a tromino to a fully covered board of width k−2k−2k−2 (i.e. f(k−2)f(k−2)f(k−2))
  2. Adding a horizontal domino to a partially covered board of width k−1k−1k−1 (i.e. p(k−1)p(k−1)p(k−1))

Summing the ways to reach p(k)p(k)p(k) gives us the following equation:
p(k)=p(k−1)+f(k−2)p(k)=p(k−1)+f(k−2)p(k)=p(k−1)+f(k−2)

Dynamic Programming (Top-down)

Algorithm
Complexity

Let NNN be the width of the board.
Time: O(N)O(N)O(N)
From top (NNN) to bottom (111), there will be NNN non-memoized recursive calls to fff and to ppp, where each non-memoized call requires constant time. Thus, O(2⋅N)O(2 \cdot N)O(2⋅N) time is required for the non-memoized calls.

Furthermore, there will be 2⋅N2 \cdot N2⋅N memoized calls to fff and NNN memoized calls to ppp, where each memoized call also requires constant time. Thus O(3⋅N)O(3 \cdot N)O(3⋅N) time is required for the memoized calls.

This leads to a time complexity of O(2⋅N+3⋅N)=O(N)O(2 \cdot N + 3 \cdot N) = O(N)O(2⋅N+3⋅N)=O(N).

Space: O(N)O(N)O(N)
Each recursion call stack will contain at most NNN layers. Also, each hashmap will use O(N)O(N)O(N) space. Together this results in O(N)O(N)O(N) space complexity.
