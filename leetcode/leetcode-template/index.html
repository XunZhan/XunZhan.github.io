Dijkstra

Quick Notes:

  1. no negative weights for edges
  2. can handle cycle
  3. can handle directed graph (which means it can also handle undirected graph)
  4. greedy algorithm

Complexity

Bellman-Ford

Quick Notes:

  1. can have negative weights for edges
  2. will fail if contains any negative cycle
  3. can handle directed graph (which means it can also handle undirected graph)
  4. dynamic programming algorithm
    4.1 dp equation: dist[v] = min(dis[v], dist[u]+weight(u,v))
    4.2 it relax the edges for V−1V-1V−1 times
    4.3 when it relax edges for KKK times, it means dist[v] stores the shortest path from source to v with at most K stops. (example: leetcode 787)

Complexity
Time: O(VE)O(VE)O(VE)
Space: O(V)O(V)O(V)

Kruskal

Quick Notes:

  1. will fail in below cases:

    1.2 directed graph: it is only for undirected graphs

  2. fits for spare graph

Space: O(V)O(V)O(V), this ignores the space used by graph
