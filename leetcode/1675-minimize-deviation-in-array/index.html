1675. Minimize Deviation in Array

Posted on 2023-02-23 Edited on 2024-04-28 In Leetcode

Problems

You are given an array nums of n positive integers.

You can perform two types of operations on any element of the array any number of times:

If the element is even, divide it by 2.
For example, if the array is [1,2,3,4], then you can do this operation on the last element, and the array will be [1,2,3,2].
If the element is odd, multiply it by 2.
For example, if the array is [1,2,3,4], then you can do this operation on the first element, and the array will be [2,2,3,4].

The deviation of the array is the maximum difference between any two elements in the array.

Return the minimum deviation the array can have after performing some number of operations.

Solutions

The problem can be solved in many ways. With heap, we can directly solve it by simulation (and a little greedy idea). Also, with some pretreatments, we can transform it into Smallest Range Covering Elements from K Lists.

Below, we will discuss five approaches: Simulation + Heap, Pretreatment + Sorting + Sliding Window, Pretreatment + Heap + Sliding Window, Pretreatment + Heap + Pointers, and Pretreatment + Sorting + Pointers.

Generally, we recommend the first approach since it is easy to implement and has good performance. We provide other approaches to explore possibilities and leave them for interested readers. In fact, there are many different approaches to tackle this problem, and the given five approaches are not enough to cover them all.

Simulation + Heap

Intuition

The problem gives two operations:

  1. If the element is even, we can divide it by 2.
  2. If the element is odd, we can multiply it by 2.

Consequently, we have two insights:

  1. If the element is even, we can not increase it.
  2. If the element is odd, we can not decrease it.

We can try to increase all numbers to their maximum and reduce them step by step.

According to the problem description: deviation=maximum−minimum\text{deviation} = \text{maximum} - \text{minimum}deviation=maximum−minimum

Hence, there are only two ways to decrease deviation\text{deviation}deviation: decrease maximum\text{maximum}maximum, or increase minimum\text{minimum}minimum.

If we have increased all numbers to their maximum, then we can not increase minimum\text{minimum}minimum. If we want smaller deviation\text{deviation}deviation, we can only decrease maximum\text{maximum}maximum.

If the maximum is odd, then we can not decrease maximum\text{maximum}maximum neither. In this case, we just return the recorded minimum deviation, since we can not decrease it anymore.

However, there is a remaining problem: we need to find the maximum and minimum after each modification. We do not want to iterate the whole list, since it is slow. Luckily, there is a data structure called heap that maintains the maximum value in logarithmic time and returns the maximum value in constant time.

For the minimum, we just need to update it for each decrease of maximum.

Pretreatment + Sorting + Sliding Window

Intuition

In Approach 1, we maintain a list and keep changing the elements of the list. Can we pre-calculate all the changeable candidates?

Yes, with a little pretreatment. For each even number, we divide it by 2 until it becomes an odd number; for each odd number, we add itself and the twice of itself.

In this case, we transform it into a similar problem: select one number from each candidate list such that the deviation is minimum. That is exactly Smallest Range Covering Elements from K Lists.

In this approach, we put all candidates into a single list and then sort the list. Suddenly, it becomes a sliding window problem. All we need to do is find out the minimum interval such that the interval contains all index’s candidates (i.e., contains all colors in the Figure below).

Of course, the length of the interval should be calculated by the difference between the ending value and the starting value. (Also, we can sort the list from large to small alternatively. That is similar.)
