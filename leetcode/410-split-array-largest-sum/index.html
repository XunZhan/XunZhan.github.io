410. Split Array Largest Sum

Posted on 2022-12-15 Edited on 2023-01-11 In Leetcode

Problems

Given an integer array nums and an integer k, split nums into k non-empty subarrays such that the largest sum of any subarray is minimized.

Return the minimized largest sum of the split. A subarray is a contiguous part of the array.

Top-Down Dynamic Programming

Intuition

The key for dynamic programming is always the equation of sub-problems. Define the recurrence relation F[currIndex, subarrayCount] to be the minimum largest subarray sum for the array [currIndex, n - 1] with subarrayCount subarrays, we can write it in the following way:

F[currIndex, subarrayCount] = min(max(sum[currIndex, i], F[i + 1, subarrayCount - 1]) ), For all i in range [currIndex, n - subarrayCount]

Time: O(N2⋅M)O(N^2 \cdot M)O(N2⋅M)
Each state is defined by the values currIndex and subarrayCount. As such, there are N⋅MN \cdot MN⋅M possible states, and we must visit almost every state in order to solve the original problem. Each state (subproblem) requires O(N)O(N)O(N) time because we have a for loop from currIndex to N - subarrayCount. Thus the total time complexity is equal to O(N2⋅M)O(N^2 \cdot M)O(N2⋅M).

Space: O(N⋅M)O(N \cdot M)O(N⋅M)
The memoization results are stored in the table memo with size N⋅MN \cdot MN⋅M. Also, stack space in the recursion is equal to the maximum number of active functions. The maximum number of active functions can be equal to MMM as we only make a recursive call when splitting the array and we do not make a recursive call when there is only 1 subarray remaining. Hence, the space complexity is equal to O(N⋅M)O(N \cdot M)O(N⋅M).

Intuition

Binary Search (Recommend)

Intuition

This problem satisfies the property that we can guess the answer (the minimum largest sum subarray value) and check if that value was too high or too low, thus narrowing our search space.

The goal of this problem is to find the minimum largest subarray sum with mmm subarrays. Instead of finding the answer directly, what if we try to guess the answer (say XXX), and check whether this particular value could be the largest subarray sum with mmm subarrays. If this is possible, we can check all values for X≥0X \geq 0X≥0, and the first value that satisfies the condition will be the answer. Thus, by repeatedly solving the following problem, we can find the minimum largest subarray sum needed to split nums into mmm subarrays:

Given an array of nnn integers and a value XXX, determine the minimum number of subarrays the array needs to be divided into such that no subarray sum is greater than XXX.

The key observation here is that if we are able to split the array into mmm or fewer subarrays for a value XXX then we will also be able to do it for any value greater than XXX. This is because the number of subarrays would be even less in case of any value greater than XXX. Similarly, if it’s not possible for a value XXX it will not be possible to have mmm or fewer splits for any value less than XXX.
