2024 年度报告

Posted on 2025-01-18 Edited on 2025-09-07 In Articles

2024年的总结

今年是我STEM OPT身份的最后一年，在旁人看来没有什么特别的，但是对我来说是非常压抑的一年。这种压抑在三月份被通知没有抽中之后达到了巅峰，因为我这三年的几乎每一天无不为这种“天意”所扰。很痛苦，很无奈，很伤心：我的去留需要像买彩票一样被决定，这彩票居然还不是我自己选的号码。朋友说：“因为你没有达到这里‘一定要把她留下’的人才标准， 所以在总体上来看，你和写不出2sum的人一样，可以用抽签决定去留，你这样人的可替代性还是很高。“ 这件事情虽然在三年前已经想清楚，但实际发生在自己身上果然是做不到知行合一的。

所以我说，我会熬下去，会坚持到不能再坚持，这次没有用尽全力，下一次可能就不会再有机会用尽全力了。我花了很多时间给自己做思想工作，也可以说这三年来有关抽签的事情，我都在试图说服自己，告诉自己最差的选择依然还有机会，只是会更加艰苦，告诉自己一切都是最好的安排，不要抗拒。到八月份的时候，我已经整理好了plan b，心理上也接受了最差的选择，甚至有时间在课余时间学点自己感兴趣的，不再去想自己的不幸运。如果我没记错，08/01/2024 12:39PM，我发现群里在讨论今年的海底捞，我顺手刷新了一下邮箱，就看到了抽中的邮件。那时候一瞬间的感觉已经忘了，只记得立刻给妈妈打了电话，坐在公司楼道的台阶上哭了很久。心里的那场绵绵不绝的雨下到每一个角落都在发霉，我早已无力清理，亦不再奢望晴天。（唉这里真是没有夸张，真是太痛了）感谢父母一直的陪伴，感谢公司的支持，感谢老板的关心，谢谢安久，你的坚持是能救命的。

今年年底爸爸妈妈来看我了，度过了百感交集的两个月。好像对生命的理解又多了些，对未来规划也新增了一些考量。我们去了三番，santa cruz，LA，2025年初的时候去了夏威夷两个岛。每一个人都很开心，很多好吃的，很多好风景，那个时候我是想多活几年的。顺便因为人变得开心了把忘川也下载回来了。

2023 年度报告

2023年的总结

2023年度总结来的格外的晚，说起来是有特别的原因但写下来又显得像是为拖延症开脱，所以就算了（也没有真的算了只是放到正文里了！）算上大大小小的实习，今年是我工作的第三个年头了，回看2021充满希望的我和2022充满困难的我，2023的我大概属于是充满冒险。冒险不像希望，她不是随时随地前方有光，冒险也不像困难，她可以随时终止也可以随时改道。冒险需要勇气，需要坚持，也需要智慧。

关于升职，在06/2023的时候，mgr开始提到这个话题并督促我完成promo doc。 08/2023我正式launch一个project并且效果很好，所以我也才在这时开始写promo doc。 在12/2023正式有了新的title然后以新的身份继续工作。我自认为是非常幸运的，那个时候市场很艰难，能有一份sde的工作已经很好，而我的mgr还一直支持帮助我走到下一个级别，我是非常感激的。我的努力确实很重要，但这个机遇依然不可多得。新的level的工作依旧是充满挑战的，这也在我的预期内，在处理问题上我也相应的调整了自己的方案：相较于new grad时不debug完不睡觉，一个问题硬解决两周，现在的我更习惯该focus就focus该睡觉就睡觉，毕竟强制要休息的脑子工作是没有任何好处的。希望今年和之后我也可以延续这个习惯。

关于生活，破天荒的我在这一年有了不一样的生活，再次非常感谢能带我开始这种生活的某人。我本来的周末都是在家里发呆或者睡大觉的，后来被拉出去hiking还有去各种没去过的山头/海边/城市看风景，意外但是也不意外的觉得很棒！所以现在会有晚上出去散步的动力。特别是加州的夏天，日落的时间比较晚，八点钟的时候太阳才开始懒洋洋的下山，她在金色的地平线上涂抹出浅紫色的柔雾，最后在一队又一队倦鸟归巢中将余晖藏进远方的大地里。每当这个时候我都觉得或许活着还有点意义。（说人话：在下班后散步能有效释放班味并有概率获得一咪咪生的希望。）

关于旅行，这个应该是作为“关于生活”的一部分，但是我想单独写一下2023年底的时候和朋友一起去的夏威夷。人生第一次“停下工作给身体和心理放假”，我确实太需要一个假期了。我和朋友去了大岛和欧胡岛，欧胡岛更像是一个开发好的旅游城市（我开玩笑说她是“小厦门”），而大岛则是我一直期待的充满野性的自然。在大岛上的白天，可以看到沿海而建的公路，干枯但仍在生长的灌木，延绵不绝的山脉。到了晚上，路灯会变成昏暗的黄色，甚至有很多路段没有路灯，沿途的动物也都已经沉睡，大海与泥土的气息会被晚风吹进车里，像是一种有安眠作用的香水，把一天的兴奋和疲惫都裹挟进记忆，等待她们被明天亦或是日后重逢再唤醒。大岛上的每一天我都觉得自己在获取生机，无论是从没见过种类的小鸟，被落日洒满金色的海滩，开车几小时才能看到的云海，还是舒适的酒店，带着滑梯的泳池，茅草屋设计的餐厅。总之，这个假期的每一个瞬间，和这个假期之后的六个月，就像是一场梦一样。令我欣喜的是，我真切的拥有过这些美好的瞬间，而且被这些瞬间持续鼓励着走向可以预见的困难。这绝对不是什么坏事。

今年是很疯狂的一年，我鼓起勇气去做了很多事，升职，旅行，改变习惯，还有更多。
这也是年度总结写晚了其中的一个理由，我从来没有经历过的很多事都在这一年发生了，所以想要一些事情尘埃落定一点再决定要用什么样的口吻来归纳2023。我承认并不是什么热爱冒险的人，但是我想让自己变得善于冒险，且能够享受冒险。

Two Pointers

Intuition

The meeting timings given to us define a chronological order of events throughout the day. We are given the start and end timings for the meetings which can help us define this ordering.

Arranging the meetings according to their start times helps us know the natural order of meetings throughout the day. However, simply knowing when a meeting starts doesn’t tell us much about its duration.

We also need the meetings sorted by their ending times because an ending event essentially tells us that there must have been a corresponding starting event and more importantly, an ending event tell us that a previously occupied room has now become free.

A meeting is defined by its start and end times. However, for this specific algorithm, we need to treat the start and end times individually. This might not make sense right away because a meeting is defined by its start and end times. If we separate the two and treat them individually, then the identity of a meeting goes away. This is fine because:

When we encounter an ending event, that means that some meeting that started earlier has ended now. We are not really concerned with which meeting has ended. All we need is that some meeting ended thus making a room available.

Solutions

Here NNN be the total number of nodes. KKK is the number of linked lists.

Brute force

  1. Traverse all linked lists and collect the value of nodes into an array.
  2. Sort and iterate over this array to get the proper value of nodes.
  3. Create a new sorted linked list and extend it with the new nodes.

Time: O(NlogN)O(NlogN)O(NlogN)
Space: O(N)O(N)O(N)

Compare one by one

  1. Compare every KKK nodes (head of every linked list) and get the node with the smallest value.
  2. Extend the final sorted linked list with the selected nodes.

Time: O(KN)O(KN)O(KN)
Almost every selection of node in final linked costs O(K)O(K)O(K) (K−1K-1K−1 times comparison). There are NNN nodes in the final linked list.
Space: O(N)O(N)O(N) for creating new nodes in linked list. O(1)O(1)O(1) for in place creation.
