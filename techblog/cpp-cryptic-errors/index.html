Solutions

According to the requirements for comparators comp(a, b), it should establish strict weak ordering relation with the following properties:

  • For all a, comp(a,a)==false
  • If comp(a,b)==true, then comp(b,a)==false
  • If comp(a,b)==true and comp(b,c)==true, then comp(a,c)==true
